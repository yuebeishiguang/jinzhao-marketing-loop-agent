# ai-copywriter · 知识增强文案

基于**本店真实好评** + **行业知识包**生成四个平台（小红书/抖音/朋友圈/大众点评）的种草文案，机制上防止「AI 味模板文案」。

## 搬走复用

1. 整个目录作为云函数部署，环境变量：`LLM_API_KEY` / `LLM_BASE_URL` / `LLM_MODEL`，超时 60 秒
2. 换行业 = 换 kb 知识包内容，函数本身不用动
3. 依赖集合：`reviews`（取真实好评）、`kb`（行业知识）、`llmUsage`（保险丝）

## 注意

- `loadPraiseQuotes` 是本组件灵魂：强制注入真实顾客原话。删掉它就退化成普通文案生成器，别删
- 知识包查询失败时内置兜底文案仍可运行，但效果打折，部署后记得跑 seedKb
